# Global Keybindings Reference

This document lists all keyboard shortcuts configured in `kde/kglobalshortcutsrc` and the Caelestia shell.

---

## 1. Window Management and Desktop Navigation

| Key Combination | Action | Subsystem |
| :--- | :--- | :--- |
| `Super + D` | Toggle desktop visibility (minimize or restore all windows) | KWin / Caelestia Taskbar |
| `Super + Tab` | Open interactive window overview | KWin |
| `Super + Q` | Close the active window | KWin |
| `Super + F` | Toggle full screen mode | KWin |
| `Super + Shift + Space` | Toggle floating state for active window | KWin |
| `Super + 1` | Switch to Desktop 1 | KWin |
| `Super + 2` | Switch to Desktop 2 | KWin |
| `Super + 3` | Switch to Desktop 3 | KWin |
| `Super + 4` | Switch to Desktop 4 | KWin |
| `Super + 5` | Switch to Desktop 5 | KWin |
| `Super + Shift + 1-5` | Move active window to Desktop 1 through 5 | KWin |

---

## 2. Shell Interfaces and Drawers

| Key Combination | Action | Subsystem |
| :--- | :--- | :--- |
| `Super` | Open or close the application launcher | Caelestia Shell |
| `Super + B` | Open or close the notification sidebar | Caelestia Shell |
| `Super + V` | Open clipboard history popup | Caelestia Shell |
| `Super + /` | Open shortcut cheatsheet overlay | Caelestia Shell |

---

## 3. Utilities and Screen Capture

| Key Combination | Action | Subsystem |
| :--- | :--- | :--- |
| `Super + Shift + S` | Capture rectangular region screenshot | Caelestia Region Tool |
| `Super + Shift + C` | Open color picker magnifying tool | Caelestia Color Picker |
| `Super + Ctrl + S` | Toggle GPU screen recorder | Caelestia Recorder |
| `Super + Shift + D` | Optical character recognition (OCR) from screen region | Caelestia OCR Tool |
| `Super + Shift + A` | Visual search tool | Caelestia Search |

---

## 4. Audio and Media Controls

| Key Combination | Action | Subsystem |
| :--- | :--- | :--- |
| `XF86AudioRaiseVolume` | Increase audio volume | WirePlumber / KWin |
| `XF86AudioLowerVolume` | Decrease audio volume | WirePlumber / KWin |
| `XF86AudioMute` | Toggle audio mute | WirePlumber / KWin |
| `XF86AudioPlay` | Toggle playback (play or pause) | MPRIS / Media Player |
| `XF86AudioNext` | Skip to next track | MPRIS / Media Player |
| `XF86AudioPrev` | Return to previous track | MPRIS / Media Player |
